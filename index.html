1. 게임 방법
  • 한영키를 안 누르고 친 질문을 머릿속으로 해독하세요.
  • 질문이 설명하는 것의 이름을 한글로 입력하면 정답!
  • 7초 안에 맞히면 [질문자 채택] 메달을 받아요.
2. 오늘의 문제
  • 매일 모두에게 같은 5문제가 나와요. 기록은 하루 1번만 남아요.
  • 5문제를 푸는 데 걸린 총 시간이 기록이에요. 짧을수록 좋아요.
  • 오답 1번마다 +3초, 패스나 60초 초과는 그 문제를 60초로 기록해요.
3. 아이템 (판당 1회)
  • 맞춤법 검사기: 띄어쓰기를 해 줘요. (+5초)
  • 지식사전: 단어 하나를 한글로 바꿔 줘요. (+5초)
  • 초성 힌트: 정답의 초성을 보여 줘요. (+10초)
4. 무한 모드 · 연속 도전
  • 무한 모드: 60초로 시작해 정답 +10초(채택 +15초), 오답 −3초. 패스는 없어요. 시간이 다 떨어질 때까지 몇 문제 버티나 도전!
  • 매일 오늘의 문제를 풀면 연속 도전 일수가 쌓여요. 하루라도 빠지면 처음부터!
